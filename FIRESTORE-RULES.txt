Paste these rules into Cloud Firestore -> Rules, then click Publish.

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

These rules do not have an expiration date. They allow signed-in Firebase users
(read/write). For a public/production website, use stricter role-based rules.
