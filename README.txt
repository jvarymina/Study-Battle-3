STUDY BATTLE - FIXED VERSION

1. Upload these files to the same GitHub Pages repository:
   index.html
   style.css
   app.js
   firebase-config.js

2. In Firebase, make sure Cloud Firestore exists and its Rules are published.
   The exact rules are in FIRESTORE-RULES.txt.

3. This version does NOT use Firebase Storage.
   Camera/gallery images are resized and compressed before being saved in Firestore.

4. Keep firebase-config.js with the Firebase config for the same project.

5. GitHub Pages must be served over HTTPS for camera access.
